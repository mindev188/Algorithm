# 코딩테스트 성장 로드맵

## 목표 레벨

이직 시장에서 Java 백엔드 개발자에게 기대되는 코딩테스트 기본기를 목표로 한다.

- 쉬운 구현 문제를 빠르게 안정적으로 푼다.
- DFS/BFS, 이분탐색, 투 포인터, 그리디, DP 기본 문제를 유형 힌트 없이 접근한다.
- 제한 조건을 보고 시간복잡도 상한을 먼저 계산한다.
- 풀이 후 반례와 복잡도를 설명할 수 있다.

## 12주 전략

### 1-2주차: 구현/문자열/배열/해시

목표:
- 입력 처리와 기본 자료구조 사용 안정화
- 문제를 코드로 옮기는 속도 향상

대표 유형:
- 빈도수 카운팅
- 문자열 파싱
- 정렬 기준 만들기
- Map/Set 사용

### 3-4주차: 스택/큐/완전탐색/재귀

목표:
- 상태를 명확히 정의하고 탐색 범위를 통제한다.

대표 유형:
- 괄호/스택
- 큐 시뮬레이션
- 조합/순열
- 백트래킹 기초

### 5-6주차: DFS/BFS/그래프

목표:
- 방문 처리, 거리 계산, 연결 요소를 실수 없이 구현한다.

대표 유형:
- 격자 BFS
- 최단거리 BFS
- 연결 요소
- DFS 재귀/반복

### 7-8주차: 이분탐색/투 포인터/슬라이딩 윈도우

목표:
- 정답 범위 탐색과 구간 최적화를 익힌다.

대표 유형:
- lower/upper bound
- 매개변수 탐색
- 연속 부분합
- 두 수/세 수

### 9-10주차: 그리디/우선순위 큐

목표:
- 정렬 기준과 선택 기준을 증명하는 연습을 한다.

대표 유형:
- 회의실/스케줄링
- 최소 비용 선택
- 힙 기반 시뮬레이션

### 11-12주차: DP 기본/실전 혼합

목표:
- 점화식과 상태 정의를 연습하고, 실전처럼 유형 혼합 문제를 푼다.

대표 유형:
- 1차원/2차원 DP
- 배낭 기초
- LIS 기초
- BFS + DP, 그리디 + 정렬 혼합
